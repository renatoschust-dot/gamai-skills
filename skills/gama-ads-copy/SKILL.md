# Ads Copy

Write ad copy that matches search intent (Google) or stops the scroll (Meta). Always produce variants for testing.

## Google Search Ads

- **Headline 1** (30 chars) — contains the primary keyword, matches the query.
- **Headline 2** (30) — the differentiator (speed, price, guarantee, location).
- **Headline 3** (30) — the CTA or a proof point.
- **Description 1** (90) — what it is + who it's for.
- **Description 2** (90) — the offer + a reason to click now.
- 3 headline variants + 2 description variants minimum.

Rules: no "best", no "cheap" without proof, no unsupported superlatives, no ALL CAPS. Include the keyword naturally in H1 — do not keyword-stuff.

## Meta Ads (Facebook / Instagram)

1. **Primary text** — first 125 characters must work as a standalone hook (before "See more").
2. **Headline** (40) — a benefit or a concrete promise.
3. **Description** (30) — a qualifier (shipping, price, guarantee).
4. **Primary CTA** — Learn More / Shop Now / Contact Us.

Write **3 angles**: problem-first, result-first, and objection-first.

## Rules

- Use the user's real numbers. If missing, use `[broj]` placeholders — never invent a discount or a statistic.
- One message per ad. Ads with two ideas underperform both.
- No misleading claims, no "guaranteed results" unless the user states the guarantee.

## Output

Table per platform: `Variant | Headline | Description | Primary text | Why this angle`.
