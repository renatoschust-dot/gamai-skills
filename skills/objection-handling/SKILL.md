# Objection Handling

An objection is not a no — it is a request for information. Answer it, then re-ask.

## The pattern (always)

1. **Acknowledge** — one line, no arguing: "Razumijem, cijena je bitna."
2. **Clarify** — ask one question to find the *real* objection.
3. **Answer** with a specific fact, not a slogan.
4. **Re-ask** — repeat the question you were blocked on.

## Common objections

| Objection | Real meaning | Response move |
|---|---|---|
| "Too expensive" | Value not proven | Ask budget; show cost-of-inaction, not features |
| "Send me info" | Avoiding the decision | Ask what would make it a yes; offer 2 options |
| "We have a supplier" | No urgency | Ask what would make them switch; offer a small pilot |
| "No time now" | Low priority | Ask when; book a specific date |
| "I need to ask my boss" | We spoke to the wrong person | Ask to join that conversation |
| "It's risky" | Trust | Offer guarantee, pilot, references |

## Rules

- Never argue, never repeat the same pitch louder.
- Never discount first — trade the discount for volume/commitment/prepayment.
- Silence after your answer: let them talk.
- If the answer is genuinely no, accept and set a follow-up date — not a re-pitch loop.
- Scripts must be in the user's language, ready to say out loud, not read.
