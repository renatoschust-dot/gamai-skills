# Content Brief

One page a writer can execute directly. No "introduction" essay about SEO.

## Brief structure

1. **Target query** + secondary queries (3-8). State the intent: informational / commercial / transactional / navigational.
2. **Who is searching** — one sentence about the searcher and what they want to do.
3. **Must-answer questions** — the actual questions the page has to answer (from the query + related searches). 5-10 items.
4. **Outline** — H1 + H2/H3 with a one-line note per section (what it must contain), not just headings.
5. **Entities & terms** — names, products, technical terms that must appear (topical completeness).
6. **Internal links** — 3-6 suggested anchors + which existing page to link to.
7. **What to avoid** — cannibalization with an existing page (name it), thin sections, fluff.
8. **Success metric** — the query we want to rank for, and the word-count *range* (not a hard number).

## Rules

- Never invent search-volume numbers. If unknown, say `volume: unknown`.
- Intent decides the format: how-to, comparison, listicle, product page.
- Every H2 must earn its place — if it can be moved to an FAQ, move it.
- The brief must be executable by someone who has never seen the site.
