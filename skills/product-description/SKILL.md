# Product Description

A listing that sells and is found. Facts first, hype never.

## Structure

1. **Title** — 60-90 chars: brand + model + product type + key spec. No ALL CAPS, no keyword stuffing.
2. **Short bullets (4-6)** — each starts with the benefit, includes the number: "3.5 kW — puni kantu za 8 minuta".
3. **Long description** — 2-3 short paragraphs: what it is, who it's for, what problem it solves.
4. **Specs table** — every technical fact: power, dimensions, weight, material, warranty, contents of the box.
5. **FAQ** — 3-5 questions customers actually ask (delivery, warranty, compatibility).
6. **SEO** — 5-8 search terms woven naturally (not a badge list at the bottom).

## Rules

- **Never invent specs or certificates.** Unknown value → `[provjeriti]`.
- Every claim must be checkable. "Durable" → "gumeni oklop, otporan na pad do 1.5 m".
- One product, one description — no comparing competitors by name.
- Match the language and units of the market (BS/HR/SR, km, cm, V, W).
- Always include warranty and what's in the box — this is what customers ask.

## Output

```
TITLE: ...
BULLETS: ...
DESCRIPTION: ...
SPECS: (table)
FAQ: (Q/A)
SEO TERMS: ...
```
