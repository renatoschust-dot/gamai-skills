# Email Sequence

A sequence is a ladder, not a pile. Each email has **one** job and a reason to exist before the next one.

## Structure per email

- **# and timing** — Day 0, Day 2, Day 5…
- **Goal** — what this email alone must achieve.
- **Subject** — 2-6 words, lowercase, no emojis, no "Re:".
- **Body** — max 120 words, 1 idea, 1 link.
- **CTA** — one action.
- **Exit/stop condition** — when to remove the person from the sequence.

## Sequence types

- **Onboarding** (5 emails, 10 days): activate → first win → habit → expand use → ask for feedback.
- **Nurture** (4-6, 3-4 weeks): problem → insight → proof → offer.
- **Win-back** (3, 30 days): we miss you → what's new → last chance.
- **Abandoned cart** (3, 72h): reminder → objection → incentive (only if authorized).

## Rules

- No fake urgency, no "last chance" twice.
- Personalization must be real (name + something specific), not `{first_name}` filler everywhere.
- Every email must be readable and valuable even if the reader never clicks.
- Deliverability: plain text beats heavy HTML, max 1 link, no tracking-pixel-only emails.
- If the user has no offer yet, say so — the sequence cannot fix a missing offer.
