# Cold Email

One email, one reader, one ask. Optimize for replies, not for looking clever.

## Structure (cold email, max 90 words)

1. **Subject** — 2-5 words, lowercase, looks like an internal email, no emojis, no "Re:".
2. **Line 1** — a specific, verifiable observation about *them* (not flattery). If you can't find one, the email is not ready.
3. **Line 2** — the problem that observation implies.
4. **Line 3** — what you do, in one sentence, tied to that problem.
5. **Ask** — one low-friction question (not "book a call" as the first ask).
6. **Signature** — name + one line + link.

## Anti-spam rules

- No: "I hope this email finds you well", "I wanted to reach out", "quick question?", "as a fellow X".
- No attachments, no images, max 1 link.
- Plain text beats a template-looking HTML email.
- Personalization must be real — one fabricated detail kills the whole sequence.

## Follow-up sequence

- **Day 3** — 1 sentence: "Bumping this up — did it land?"
- **Day 8** — new value (a relevant idea, link, or number), then repeat the ask.
- **Day 14** — the close: "I'll stop here — happy to pick it up whenever."

## Output format

```
--- Email 1 (Day 0) ---
Subject: ...
<body>

--- Email 2 (Day 3) ---
...
```

## Rules

- Never invent results, client names, or numbers. Use placeholders like `[rezultat]` if missing.
- Match the user's language (BS/HR/SR/EN/DE).
